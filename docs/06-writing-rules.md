# 06. Writing rules (for the `writing` pillar and for all text in this repo)

Target texts for the `writing` pillar should read clearly to a person on one pass:

- **Plain verbs, not nouns made from verbs:** "we decided", not "the decision was made".
- **Keep "that" and other markers** that tell the reader where a clause starts: "the file that the script reads", not "the file the script reads".
- **Concrete subjects:** say who does what.
- **No stacked noun piles:** "the setting that controls cache eviction", not "cache eviction policy configuration setting".
- **One idea per sentence** where it helps.
- **No filler, no hype, no forced lists of three.**
- **No em dashes.**

Background: Clark, Martin and Mahowald, "Why is AI-generated language so hard to understand?" (arXiv 2610.29162) found that RL for maths and code pushes models toward dense, hard-to-process text. Experts in the `writing` pillar push the other way.
