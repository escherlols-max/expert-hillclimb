# 05. Submitting

Open a pull request that adds one folder:

    submissions/<pillar>/round-NN/<expert-id>/<your-handle>-<short-name>/
        overlay.npz      # the tuned expert's three matrices (or a translated branch: maps + donor expert + a)
        report.json      # output of score_expert.py, plus a "notes" field: what you tried, what failed
        method.md        # how to reproduce: exact commands, seeds, data sources

## Rules
1. **Score only on CPU,** deterministically, with `tools/score_expert.py` at the round's pinned version.
2. **One expert or translated branch per folder.** Several submissions are fine.
3. **No data generated by Anthropic Claude models** anywhere in your pipeline: not as targets, labels, judges or hints. Name every model you used in `method.md`.
4. **Licences:** any donor expert or teacher must allow modification and redistribution.
5. **No em dashes** in any text you add.
6. **Secrets:** no secrets, tokens or personal data in any file.

## What happens next
- **CI** re-scores your overlay and posts the score.
- **Leaderboards:** `leaderboard/<pillar>.md` shows the top VALID scores per expert.
- **GPU check:** the leaders per expert are merged into the full model and checked on held-out exams on GPU. Results are posted on the leaderboard as `exam_delta`. A proxy winner that hurts the exams is marked and demoted.
